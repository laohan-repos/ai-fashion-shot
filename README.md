# 穿影 · AI Fashion Shot

穿影是一个面向服装展示、电商内容制作和时尚创作者的 AI 图片与短视频生成工作台。

项目将模特素材、服装素材和生成式 AI 模型整合到一套可视化工作流中，帮助用户完成从素材整理到服装展示视频制作的全过程。

## 核心功能

- 模特与服装素材分组管理
- 本地图片上传与 AI 素材生成
- 图片编辑及历史版本管理
- 根据参考模特生成四视图
- 将多件服装合成为完整白底穿搭图
- 组合模特、服装和场景生成模特穿衣图
- 根据穿衣图生成 Seedance 短视频
- 作品管理与制作进度展示
- 模型服务地址、模型名称和 API Key 配置
- 生成请求、响应、图片及视频结果本地归档

## 制作流程

1. 添加模特和服装素材
2. 生成模特四视图
3. 生成服装白底搭配图
4. 生成指定场景下的模特穿衣图
5. 生成服装展示短视频

## 技术栈

- Next.js 14
- React 18
- Next.js App Router
- Node.js
- SQLite
- ImageMagick
- GPT Image 兼容接口
- Seedance 视频生成接口

## 本地运行

环境要求：

- Node.js 22 或更高版本
- ImageMagick

```bash
npm install
npm run dev
```

启动后访问 [http://localhost:3000](http://localhost:3000)，并在“模型”页面配置所需的图片和视频生成服务。

## 数据存储

项目默认将运行数据保存在以下位置：

- `data/`：SQLite 数据库和模型生成记录
- `模特穿搭图/`：生成的模特穿衣图片
- `模特视频/`：生成的视频文件

上述目录已经加入 `.gitignore`，不会提交到仓库。
