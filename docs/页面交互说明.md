# 学员版页面交互说明｜穿影 AI 服装视频工作台

## 1. 文档用途

本文档定义“穿影”MVP 的页面结构、用户操作、界面状态、数据变化和异常反馈，供学员使用 Codex 从零实现和验收。

它可用于：

- 学员在 Vibe Coding 前理解产品交互。
- 开发过程中对照页面行为。
- 功能完成后进行手工验收。
- 将设计图中的静态画面转化为可执行、可验证的交互规则。

本文档只规定用户能够看到和操作的结果，不规定组件拆分、状态管理或具体代码写法。学员应让 Codex 先复述目标交互，再逐页实现并在浏览器中验证。

## 2. 页面地图

| 页面 | 路由 | 主要用途 |
| --- | --- | --- |
| 首页 | `/` | 自动跳转到作品列表 |
| 作品列表 | `/projects` | 查看、创建、编辑、删除和打开作品 |
| 作品工作台 | `/projects/{projectId}` | 完成四步 AI 服装视频工作流 |
| 素材库 | `/assets` | 管理搭配、模特图和服装图 |
| 模型配置 | `/model-config` | 配置和测试 AI 模型连接 |

## 3. 全局导航

### 3.1 PC 端导航

左侧固定导航包含：

- `作品`：进入作品列表。
- `素材`：进入模特与服装素材库。
- `模型`：进入 AI 模型配置页。

当前页面所对应的导航项保持选中状态。切换导航时使用客户端路由，不整页刷新。

### 3.2 手机端导航

- 屏幕宽度不足时不保留固定侧边栏，改用紧凑的顶部栏或底部导航。
- `作品`、`素材`、`模型`三个主要入口最多一次点击可达。
- 页面标题、返回操作和当前步骤必须保持可见，不依赖鼠标悬停。
- 展开菜单后，点击菜单项或遮罩区应关闭菜单。
- 页面滚动时不得让导航遮挡主要操作按钮。

### 3.3 通用弹窗行为

- 点击弹窗外遮罩区可关闭多数弹窗。
- 数据正在保存、生成或删除时，应禁止关闭相关弹窗。
- 取消操作不保存本次输入。
- 删除弹窗必须明确展示删除对象和不可恢复的影响。
- PC 端弹窗居中显示；手机端可使用接近全屏的弹窗或底部操作面板。
- 手机端弹出键盘后，当前输入框和提交按钮仍应可以滚动到可见区域。

### 3.4 响应式通用规则

| 内容 | PC 端 | 手机端 |
| --- | --- | --- |
| 页面布局 | 导航与内容并排，充分利用横向空间 | 单列排列，次要信息折叠 |
| 表格 | 按列展示完整信息 | 改为卡片，不压缩成不可读表格 |
| 多栏表单 | 可并排展示相关字段 | 字段纵向排列 |
| 主操作 | 位于页面右上或内容区底部 | 位于标题下方或底部操作区 |
| 图片列表 | 多列网格 | 2 列为主，窄屏可降为 1 列 |
| 制作步骤 | 横向页签完整展示 | 可横向滚动，当前步骤自动进入可见区域 |

响应式验收以 1440×900 和 390×844 两个视口为基准。除步骤页签、图片画廊等有意设计的局部区域外，页面不得产生横向滚动。

## 4. 作品列表页

### 4.1 页面加载

1. 进入页面后显示“正在读取作品…”。
2. 数据读取成功后显示作品表格。
3. 没有作品时显示空状态和“新建作品”按钮。
4. 读取失败时在页面中显示错误信息。

### 4.2 作品列表

每行展示：

- 作品名称和说明。
- 已完成步骤，格式为 `x/4 步`。
- 进度条和完成百分比。
- 最近更新时间。
- `编辑`、`删除`、`打开` 操作。

点击整行或“打开”按钮进入作品工作台。点击“编辑”和“删除”时不触发整行的打开操作。

手机端不使用多列表格，每个作品显示为独立卡片；名称、进度和“打开”作为主要信息，说明、更新时间、编辑和删除作为次要信息排列在卡片内部。

进度计算规则：

1. 已生成模特四视图：25%。
2. 已生成服装白底图：25%。
3. 已生成模特穿衣图：25%。
4. 已成功生成至少 4 个视频：25%。

### 4.3 新建作品

1. 点击“＋ 新建作品”打开弹窗。
2. 输入作品名称，最多 40 个字符。
3. 可选填写作品说明，最多 120 个字符。
4. 名称为空时显示“请输入作品名称”。
5. 点击“创建并打开”后，按钮变为“保存中…”。
6. 创建成功后关闭弹窗，刷新列表并直接进入新作品。

### 4.4 编辑作品

1. 点击作品行内的“编辑”。
2. 弹窗回填当前名称和说明。
3. 修改后点击“保存修改”。
4. 成功后关闭弹窗并刷新作品列表。

### 4.5 删除作品

1. 点击“删除”打开确认弹窗。
2. 弹窗提示作品中的生成记录将一并删除。
3. 点击“确认删除”后显示“删除中…”。
4. 成功后关闭弹窗并刷新列表。

### 4.6 批量生成（可选扩展）

点击“批量生成”打开批量任务弹窗。

扩展交互要求：

- 只展示尚未产生生成结果的搭配。
- 同时具有模特和服装的搭配默认全选。
- 素材不完整的搭配不可选。
- 可全选或取消全选。
- 未选择搭配时不可进入下一步。
- 确认页显示将创建的作品数量和前三个生成步骤。
- 执行页显示各搭配的步骤状态和总进度。
- 支持点击关闭按钮、遮罩区或按 `Escape` 关闭。

> 批量生成不属于 MVP 验收范围。未实现真实任务前，不应在正式流程中提供看似可用的入口；课程扩展阶段实现时，必须创建真实作品并调用真实或 Mock 生成任务，不能只播放假进度。

## 5. 素材库页

### 5.1 页面结构

页面由两部分组成：

- 左侧“我的搭配”分组列表。
- 右侧当前搭配的模特素材和服装素材。

手机端先显示当前搭配选择器，再显示模特和服装素材；搭配列表通过抽屉或下拉面板打开，选择后自动关闭并刷新当前素材。

搭配状态根据素材情况显示：

- `待添加`：没有模特和服装。
- `缺模特`：只有服装。
- `缺服装`：只有模特。
- `已备齐`：同时存在模特和服装。

### 5.2 新建搭配

1. 点击页面右上角“＋ 新建搭配”，或左侧的加号。
2. 输入搭配名称，最多 24 个字符。
3. 名称不可为空，也不可与已有搭配重名。
4. 创建成功后自动选中新搭配。

### 5.3 重命名和删除搭配

- 点击铅笔按钮打开重命名弹窗，修改名称不影响已有素材。
- 点击删除按钮打开确认弹窗。
- 删除搭配会同时删除其中的模特、服装和素材编辑版本。
- 删除当前选中搭配后，右侧素材列表清空，并自动选择其他可用搭配。

### 5.4 上传素材

1. 在模特或服装区域点击“选择图片”。
2. 可一次选择多张 JPG、PNG 或 WebP 图片。
3. 上传期间显示“正在保存…”，其他上传按钮禁用。
4. 系统按文件顺序逐张上传，并分别记录成功或失败结果。
5. 全部成功后刷新素材和搭配状态。
6. 任一文件失败时显示错误信息；已上传成功的文件不回滚。

### 5.5 AI 生成素材

1. 展开“没有合适的模特/服装照片？”。
2. 填写模特或服装描述。
3. 选择 `9:16`、`1:1` 或 `16:9` 比例。
4. 选择生成 `1`、`2` 或 `4` 张。
5. 提示词为空时生成按钮禁用。
6. 生成中按钮显示运行状态。
7. 成功后新图片自动加入当前搭配。

### 5.6 图片预览与编辑

1. 点击素材图片打开编辑弹窗。
2. 左侧显示当前选中版本和版本缩略图。
3. 点击版本缩略图切换编辑起点。
4. 右侧填写修改提示词，也可使用预设按钮填入提示词。
5. 选择竖版、方形或横版输出尺寸。
6. 提示词为空时“生成新版本”禁用。
7. 新版本生成成功后自动选中，原图不被覆盖。
8. 编辑中不可关闭弹窗。

### 5.7 删除素材

1. 点击素材卡片的“•••”。
2. 选择“删除照片”。
3. 确认弹窗显示图片预览和历史版本数量。
4. 确认后删除原图及全部编辑版本。

## 6. 作品工作台

### 6.1 顶部区域

- 返回按钮：返回作品列表。
- 面包屑：显示“服装视频作品 / 作品名称”。
- 保存状态：只在数据确实完成持久化后显示“已保存”，保存中和失败时必须显示对应状态。
- “生成视频”：点击后进入第四步；只有第四步中的生成按钮可以真正提交视频任务。

手机端顶部区域分两行显示：第一行提供返回操作和作品名称，第二行显示保存状态与主要操作；过长作品名称使用省略号，点击后可查看完整名称。

### 6.2 步骤导航

工作台包含四个页签：

1. 模特四视图。
2. 服装白底图。
3. 模特穿衣图。
4. 模特视频。

点击页签可任意切换，不强制按顺序进入。如果前置数据缺失，目标步骤显示空状态或禁用生成按钮。

手机端步骤导航允许横向滑动或滚动。切换步骤后页面回到该步骤内容顶部，不保留上一步的深滚动位置。

键盘交互：

- `←` / `→`：循环切换上一个或下一个步骤。
- `Home`：跳到第一步。
- `End`：跳到第四步。

## 7. 第一步：模特四视图

### 7.1 选择来源

1. 选择一个搭配分组。
2. 界面加载该搭配中的模特素材。
3. 点击图片选中或取消，最多选择 4 张。
4. 超过 4 张时显示“最多选择 4 张参考图”。
5. 没有选择图片时，生成按钮禁用。

手机端点击图片卡片本身完成选择，选中状态必须同时使用边框、勾选标记或编号表达，不能只依靠颜色。

首次四视图生成成功后，当前作品的搭配分组被锁定，在第一、第二步中都不可切换。

### 7.2 提示词

- 点击“提示词”打开编辑弹窗。
- 最多输入 1000 个字符，页面显示字符数。
- 点击“清空”删除当前自定义内容。
- 点击“保存提示词”只保存到当前页面状态，不单独写入数据库。

### 7.3 生成与结果

1. 点击“生成模特四视图”。
2. 生成中按钮显示“四视图生成中…”。
3. 成功后显示横向四联图，顺序为正面、左侧、右侧、背面。
4. 点击结果图打开放大与编辑弹窗。

### 7.4 编辑与版本

- 左侧可在原图和历史版本中切换。
- 可使用“修改基础服”“优化质感”“统一比例”预设提示词。
- 输入提示词后可基于任意版本创建新版本。
- 原图不可删除；选择历史版本时可点击“删除当前版本”。
- 删除版本前在当前弹窗内再次确认。

## 8. 第二步：服装白底图

### 8.1 选择服装

1. 使用作品当前关联的搭配分组。
2. 如果第一步已完成，搭配选择被锁定。
3. 点击服装图片选中或取消，最多选择 6 张。
4. 超过 6 张时显示限制提示。
5. 没有选择服装时，生成按钮禁用。

### 8.2 提示词与生成

- 提示词弹窗默认包含白底图内置提示词。
- 用户可直接修改，最多 1000 个字符。
- 点击“恢复默认”重置为内置内容。
- 生成时将所选服装合成一张 3:4 白底图。
- 成功后显示生成图和源素材名称。
- 重新生成会替换当前作品的白底图结果。

手机端素材选择区使用双列网格，底部汇总“已选择 x/6”；生成按钮应在选择过程中容易到达，但不得遮挡最后一行素材。

## 9. 第三步：模特穿衣图

### 9.1 前置数据

- 模特来源为第一步的四视图原图或历史版本。
- 服装来源为第二步的白底图。
- 前置数据缺失时，来源卡片显示“请先完成第一/二步”，生成按钮禁用。
- 有多个四视图版本时，可使用下拉框选择模特来源。
- 默认使用第二步返回的第一张白底图。

### 9.2 选择场景

预设场景包含：

- 高级室内。
- 城市街拍。
- 精品咖啡馆。
- 商场橱窗。
- 极简展厅。
- 自定义场景。

选择自定义场景后显示文本框，最多 300 个字符。自定义描述为空时不可生成。

### 9.3 生成穿衣图

1. 用户可打开提示词弹窗，修改人物一致性、服装还原和场景融合要求。
2. 提示词最多 1200 个字符，可恢复默认。
3. 点击“生成模特穿衣图”后显示生成状态。
4. 生成成功后将新结果放在结果列表最前。
5. 已有结果时，按钮文案变为“再生成一张”。
6. 多次生成不覆盖历史结果。
7. 每张结果显示编号、场景和 `3:4` 标识。

手机端按“来源选择 → 场景选择 → 提示词 → 生成按钮 → 结果”的顺序单列排列，生成结果不得出现在用户看不到的横向区域。

## 10. 第四步：模特视频

### 10.1 选择首帧

- 未生成穿衣图时，首帧区显示“请先完成第三步模特穿衣图”。
- 只有一张穿衣图时自动使用该图。
- 有多张穿衣图时，显示下拉框，可按编号和场景选择。
- 切换穿衣图后，页面同步更新场景、脚本、任务状态和视频预览。

### 10.2 视频参数

- 视频比例：`9:16`、`1:1` 或 `16:9`。
- 时长：5 秒，MVP 阶段不可修改。
- 清晰度：480p，MVP 阶段不可修改。
- 音频：无声。
- 水印：关闭。
- 机位：平稳跟随。

### 10.3 场景与脚本匹配

系统根据穿衣图的场景自动选择脚本：

| 场景 | 脚本 |
| --- | --- |
| 高级室内 | 高级室内展示 |
| 城市街拍 | 城市街拍漫步 |
| 精品咖啡馆 | 咖啡馆随拍 |
| 商场橱窗 | 橱窗时尚展示 |
| 极简展厅 | 极简展厅定格 |
| 其他场景 | 生成一条场景自适应脚本 |

脚本提示词最多 1200 个字符。用户可修改提示词，也可点击“恢复默认”。脚本为空时生成按钮禁用。

### 10.4 提交与轮询

1. 点击视频生成按钮。
2. 界面显示“正在提交…”。
3. 远程任务创建成功后，显示“正在等待 Seedance 生成…”。
4. 首次等待 1.5 秒，之后每 3 秒查询一次任务。
5. 最多查询 180 次。
6. 成功后显示视频，并保存到本地“模特视频”文件夹。
7. 失败时显示红色错误卡片，用户可关闭后修改脚本重试。
8. 已有成功结果时，按钮文案变为“重新生成”。

用户离开第四步或刷新页面后，再次进入时应根据已保存的任务状态继续展示结果；不得仅依赖当前页面内存保存轮询状态。

### 10.5 已生成视频

- 当前穿衣图和脚本对应的成功视频显示在脚本右侧。
- 页面底部展示当前作品的全部成功视频。
- 每个视频卡片显示脚本名、穿衣图 ID 和时长。
- 点击“下载视频”通过浏览器下载 MP4 文件。

手机端视频播放器占满内容宽度，保持视频比例；下载操作必须使用可点击按钮，不依赖鼠标悬停出现。

## 11. 模型配置页

### 11.1 模型切换

左侧可选择：

- 多模态模型。
- GPT Image 2 图生图。
- GPT Image 2 文生图。
- Seedance 视频模型。

切换类型后加载该类型的已保存配置。加载期间表单显示处理状态。

手机端使用顶部选择器或横向可滚动页签切换模型类型，选择器不得与配置表单并排挤压。

### 11.2 配置字段

- 启用开关。
- API 地址。
- 模型名称。
- API Key。

已存在 API Key 时，密钥输入框保持空白，占位文字提示“已安全保存，留空则不修改”。点击“显示/隐藏”只切换本次输入内容的显示方式，不会读取已保存密钥。

### 11.3 测试连接

1. 点击“测试连接”。
2. 当前表单已填 API Key 时使用当前值，否则使用服务端已保存的密钥。
3. 测试中显示“正在连接模型服务…”。
4. 成功或失败后显示结果和耗时。
5. 结果约 5 秒后自动消失。

常见反馈包含：连接成功、认证失败、模型未出现在模型列表、连接超时和无法连接。

### 11.4 保存配置

1. API 地址和模型名称不可为空。
2. 点击“保存配置”后按钮显示“保存中…”。
3. 输入新 API Key 时更新密钥；留空时保留原密钥。
4. 成功后显示“配置已保存到 SQLite”。
5. 结果约 2.8 秒后自动消失。

## 12. 反馈和禁用规则

| 场景 | 界面反馈 |
| --- | --- |
| 正在读取数据 | 显示加载文案或加载样式 |
| 正在上传 | 上传按钮显示正在保存，并禁止重复选择 |
| 正在生成图片 | 生成按钮更换文案并禁用 |
| 正在生成视频 | 首帧和脚本不可修改，生成按钮禁用 |
| 缺少前置结果 | 显示“请先完成第 x 步”，相关按钮禁用 |
| 输入为空 | 保存或生成按钮禁用，或提交后显示字段错误 |
| 操作成功 | 刷新结果区域，显示短暂成功提示 |
| 操作失败 | 保留已有数据，显示服务端返回的可读错误 |
| 危险删除 | 先显示二次确认，确认后禁用其他操作 |

## 13. 数据刷新规则

- 新建、编辑或删除作品后，重新读取作品列表。
- 上传、生成或删除素材后，同时刷新素材列表和搭配状态。
- 四视图或白底图生成后，向后续步骤发出来源数据更新事件。
- 穿衣图生成后，第四步自动重新读取可用首帧。
- 视频任务轮询期间，只更新对应任务，不覆盖其他视频任务。

## 14. MVP 交互边界

1. 四个制作步骤允许自由切换，但缺少前置结果时必须明确说明原因并禁止提交。
2. 图片和视频生成必须接入真实模型或教师提供的 Mock 服务，不允许仅用定时器播放假进度作为完成结果。
3. “已保存”“生成中”“生成成功”等状态必须来自真实数据变化，不能只是按钮文案变化。
4. 批量生成属于可选扩展；如果未实现，应隐藏入口或明确标记为“即将开放”。
5. PC 端和手机端自适应页面都属于 MVP，不能将小屏适配推迟为课后选做。
6. MVP 不要求登录、多用户协作、支付、发布到社交平台或移动端原生应用。

## 15. 手工验收主路径

1. 打开作品列表，新建一个作品。
2. 进入素材库，创建搭配。
3. 上传一组模特图和多张服装图。
4. 分别打开图片，创建并切换一个编辑版本。
5. 进入模型页，配置并测试图片与视频模型。
6. 回到作品工作台，选择搭配并生成模特四视图。
7. 确认搭配已锁定，创建一个四视图编辑版本。
8. 选择服装素材并生成白底图。
9. 选择四视图版本、白底图和场景，连续生成两张穿衣图。
10. 切换穿衣图，检查场景脚本是否自动匹配。
11. 修改视频脚本，提交视频并观察任务状态。
12. 视频成功后在页面播放并下载。
13. 刷新页面，确认作品、素材和生成结果仍然存在。
14. 返回作品列表，确认制作进度和更新时间已变化。

### 15.1 手机端补充验收

使用 390×844 视口重复以下操作：

1. 通过手机端导航进入作品、素材和模型页面。
2. 新建作品和搭配，确认键盘不会遮挡输入框与提交按钮。
3. 选择模特和服装素材，确认选中状态清晰且操作区域不过小。
4. 横向切换四个制作步骤，确认当前步骤始终可见。
5. 完成生成操作，确认加载、错误和成功反馈不会超出屏幕。
6. 播放并下载生成视频，确认播放器宽度和比例正确。
7. 检查所有页面不存在影响使用的整页横向滚动。
